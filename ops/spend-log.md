# Pareto spend log

*Every dollar of the $200 Anthropic API credit. A notebook file that goes straight to `main`.*

**How it works**
- **The chat that ran the paid job adds one row after it**, almost always Friday. The row uses the cost
  computed from the run's logged usage × the pinned price table, and is checked against the Anthropic
  Console. Commit it straight away, with an explicit path.
- **Jarvis keeps the summary** below up to date and reports the totals to the user.
- **The account:** Anthropic API, $200 of credit. A Console spend limit is recommended as a backstop
  (decision D-12).
- **Safety:** every paid script runs dry by default, reserves each call's worst-case cost before sending
  it, and stops at a hard cap. The rules are in `harness/README.md`. No paid run happens without Edith's
  clearance and the user's "go".
- **Not counted here:** the Claude Max plan, which runs the chats and the research helpers. Only API
  credit goes in this log.
